# WebGL2 三角形占位

这里还没有可运行的示例，也没有 ESSL 源文件。`crates/glgpu-webgl` 里的 `WebGl2LearningTrack::create_context` 会返回 `NotStarted`。

这个目录只标记以后的学习切片：在 CPU 上从零画出一个 WebGL2 风格的三角形，不调用浏览器 `WebGL2RenderingContext` 或 `navigator.gpu`。在那次切片落地之前，不要把 WGSL P0 demo（[`../triangle`](../triangle/README.md)）当成 WebGL2 路径。

说明见 [WebGL2 学习轨道](../../docs/webgl2-learning-track.zh-CN.md)。
